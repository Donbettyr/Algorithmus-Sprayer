Einstellungen
Der Key bleibt in diesem Browser. Eine Suche kostet 101 von 10.000 Tageseinheiten (100 Suche + 1 Video-Prüfung). Teile deinen Key nicht öffentlich. Spielt ein offizielles Beispielvideo ab – ohne API-Key, Wikipedia oder Suchserver. Der Sprayer-Zähler bleibt unverändert.
So bekommst du einen Key
  1. In der Google Cloud Console ein Projekt anlegen.
  2. Die YouTube Data API v3 aktivieren.
  3. Unter Anmeldedaten einen API-Schlüssel erstellen und hier einfügen.
  4. Empfohlen: den Schlüssel auf die YouTube Data API v3 beschränken.
